Official executive portfolio of **Eng. Majid Mohammed Aloraidi**.

- **Live site:** https://majidaloraidi.com
- **GitHub Pages:** https://majidaloraidi.github.io

## Deploy notes

This is a production-built single-page React application (static).

### Custom domain

The `CNAME` file is already included so GitHub Pages will serve this on `majidaloraidi.com`.

## How to update

1. Replace `index.html` with a new production build
2. Commit & push to the `main` (or `gh-pages`) branch
3. GitHub Pages will update automatically (usually < 1 minute)
